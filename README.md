# 摄像头 AI 工作台

面向固定摄像头的个人活动记录工具：从 RTSP 画面生成活动时间线、分钟记录和小时／日报，并保留文字结论与现场图片之间的可追溯关系。默认关注机位中的主要活动；人物和物品档案用于辅助识别，不替代活动判断。业务时间统一使用北京时间。

## 功能概览

- 管理摄像头、采集时段和关注区域；查看实时画面与设备状态。
- 保存采集画面并调用 OpenAI 兼容的视觉服务分析；区分无活动、等待或处理中、分析失败、未取得画面等状态。
- 查看跨分钟活动事件、分钟记录、小时汇总和日报；活动时长由后端规则计算。
- 按需管理分析生成的人物／物品档案，可调整档案名称、合并或拆分，并控制是否自动新增。
- 现场图片按保留期限到期后，文字记录仍可查看。

## 当前实现状态

活动记录、自动档案及本地软件契约已有实现和自动化验收。时间片观察与上级多轮裁决已有基础执行链路，仍在生产验收中；真实摄像头、外部模型服务、VPS 长时间运行和手机实机尚未完成完整联调，不视为已验证的端到端能力。

## 技术栈

- **前端：** React、TypeScript、Vite、React Router、TanStack Query
- **后端：** Python 3.11+、FastAPI、SQLAlchemy、Alembic；API 与持久任务 worker 分进程运行
- **数据与采集：** SQLite、FFmpeg、RTSP
- **分析：** OpenAI 兼容视觉服务

## 本机启动

需要 Python 3.11 或更新版本、Node.js/npm，以及已安装并加入 `PATH` 的 FFmpeg。在仓库根目录运行：

```powershell
.\start-local.ps1
```

脚本会按需准备 Python 虚拟环境和前端依赖；首次运行会要求设置管理员密码。启动后访问 <http://127.0.0.1:5173>。在启动终端按 `Ctrl+C`，或在另一终端运行以下命令停止：

```powershell
.\start-local.ps1 -Stop
```

前端单独开发、后端配置和部署步骤分别见下方组件说明；根目录 `.env.example` 是本机启动配置样例。

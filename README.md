# 摄像头 AI 工作台

通过摄像头画面形成可追溯的活动、分钟记录与小时／日报。活动时长由后端计算，无法判断、未分析和采集缺口分别保留；现场图按期限到期，文字记录继续可读。业务时间统一使用北京时间。

- [前端运行与构建](frontend/README.md)
- [后端运行与部署](backend/README.md)
- [视觉与交互设计](DESIGN.md)
- [逐项前端验收与截图](docs/06-前端实现与验收清单.md)

前端为 React + TypeScript + Vite，运行 `cd frontend`、`npm ci`、`npm run dev`；正式部署使用 `npm run build` 生成的 `dist/`，与后端放在同一 HTTPS 来源。详见两个运行说明中的连接与鉴权配置。

正式应用不包含 Demo 数据入口。验收使用的合成摄像头、模型响应和临时数据库仅存在于测试脚本中；实际手机、家庭网络链路和外部模型服务需要在部署环境复核。

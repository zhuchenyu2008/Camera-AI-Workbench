# 后端实现与逐项验收

日期：2026-10-17（北京时间）。设计基线：[后端详细设计与接口契约](04-后端详细设计与接口契约.md)。

后端代码、迁移、API、worker、测试、依赖锁和部署模板已落地。当前确认本地软件实现与契约验收；目标 VPS、真实摄像头／模型服务、前端与手机尚无可用联调环境，不将 B12、语义指标或完整首版标为通过。

本地环境：Windows、Python 3.11.9、FFmpeg 8.0.1。新建虚拟环境不继承系统包，安装 `backend/requirements.lock` 的38项固定依赖后验收，`pip check` 通过。数据库迁移版本 `0003`，HTTP schema `1.0`。

本地验收包含43项 pytest 用例、Ruff检查与格式检查、契约产物一致性检查、TypeScript 5.9.3严格编译。GitHub Actions 已在 Linux 对代码提交 `dff4230` 复跑全部检查并通过：[CI 验收记录](https://github.com/zhuchenyu2008/Camera-AI-Workbench/actions/runs/39016007328)。

## 复现与部署

在 `backend` 目录使用实际虚拟环境解释器执行：

```text
python -m pip install -r requirements.lock
python -m pytest -q
ruff check app migrations scripts tests
ruff format --check app migrations scripts tests
python -m scripts.build_contracts --check
npx --yes --package typescript@5.9.3 tsc --noEmit --strict --lib ES2022,DOM contracts/api-types.ts
```

部署与回退见 [backend/deploy/README.md](../backend/deploy/README.md)。现场需填写VPS系统／架构、HTTPS域名、frp visitor端口、摄像头路径／编码、AI服务域名／模型。凭据通过本地环境和仓库外主密钥设置，不提交Git。现有用户摄像头测试文件未修改、未纳入后端提交。

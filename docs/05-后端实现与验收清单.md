# 后端实现与逐项验收

日期：2026-10-17（北京时间）。基线：[后端详细设计与接口契约](04-后端详细设计与接口契约.md)。

本清单区分代码、本地自动化和真实设备验收。仓库最初只有设计文档；实际 VPS、摄像头、AI 服务和前端尚未提供可用联调环境，不能把代码存在或假服务通过写成生产验收通过。

| 实施顺序 | 实现位置 | 当前核对 |
| --- | --- | --- |
| 契约与存储 | `backend/app/schemas`、`repositories`、`api`、`security`、`migrations` | 初始迁移、登录、CSRF、版本／幂等、完整接口目录已接入；首轮 4 项自动化测试通过 |
| 接入与生命周期 | `capture`、`detection`、`worker/cleanup.py` | 已编写，继续运行集成验收 |
| 分析闭环 | `analysis`、`services/analysis.py`、`worker` | 已编写，继续验证假服务与恢复路径 |
| 时间账本 | `activities`、`summaries` | 已编写，继续运行守恒、去重、人工修订与失效测试 |
| 完整交付 | CLI、部署配置、契约导出、验收记录 | 正在补齐 |

接口测试从设计文档第 4.3 节读取路由表，与实际 OpenAPI 的方法、路径和 operation_id 集合逐项比较，防止漏接口。

实际摄像头语义质量、目标 VPS 24 小时容量、手机预览和前端真实联调，在拿到对应环境前保持“待实测”。
